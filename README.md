# ML-DQN
This project implements a Deep Q-Network (DQN) to solve game environments from the gymnasium library. It utilizes key deep reinforcement learning concepts such as policy and target networks, replay memory, and configurable hyperparameters via YAML files.

## Features
Policy and Target Networks: Implements separate networks to stabilize training.\
Replay Memory: Stores experiences (transitions) to break correlations and enable efficient mini-batch training.\
YAML Configuration: Easily manage and adjust hyperparameters such as learning rate, discount factor, batch size, and more.\
Gymnasium Environment Integration: Designed to work seamlessly with environments from the gymnasium library.
